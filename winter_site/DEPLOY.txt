29 Championship Series — бесплатная публикация

1. Загрузите СОДЕРЖИМОЕ папки winter_site в приватный репозиторий GitHub.
2. Render -> New -> Web Service -> GitHub repository.
   Build command: npm install
   Start command: npm start
3. Environment variables:
   ADMIN_USER = ваш логин
   ADMIN_PASSWORD = ваш уникальный пароль (минимум 12 символов)
   COOKIE_SECURE = true
4. После запуска откройте публичный URL Render.

ВАЖНО:
- Админка доступна после входа, изменения сохраняются на сервере.
- На бесплатном Render файловая система НЕ постоянная. Изменения в server-data.json
  могут пропасть при перезапуске или новом деплое. Для постоянных данных
  нужна внешняя база данных. Не используйте админку для критичных данных,
  пока не подключена постоянная база.
- Исходный архив не содержал серверной админки; она добавлена здесь.
- Результаты плей-офф CS2 и объединение Zenpai/zenpa17 восстановлены из
  информации в текущем разговоре.
